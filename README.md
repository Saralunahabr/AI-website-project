# ai-project

A one-page explainer on artificial intelligence, "Who checks the machine?", for the Webs and Apps Design course at IE University.

- `index.html`: the page (semantic HTML)
- `styles.css`: layout, colors and type (light and dark mode)
- `script.js`: optional filter that shows only facts, interpretations or predictions
- `assets/checkpoints.svg`: the diagram

Published with GitHub Pages from the `main` branch, root folder.
